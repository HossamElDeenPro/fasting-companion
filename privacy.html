Privacy Policy

Fasting Companion Chrome Extension  ·  Last updated: 2025

Summary: Fasting Companion collects no personal data. Everything stays on your device. No servers, no tracking, no analytics.

1. Who We Are

Fasting Companion is a free Chrome Extension designed to help Muslims track recommended fasting days, Hijri dates, and Qada (makeup fasts). It is developed as an independent open utility with no commercial affiliations.

2. Data We Collect

We collect no personal data whatsoever. The extension does not collect, transmit, or store:

  • Your name, email address, or any identifier
  • Location or IP address
  • Browsing history or activity
  • Device information
  • Usage statistics or analytics

3. Data Stored Locally

The extension stores the following data locally on your device only, using the Chrome storage.local API. This data never leaves your device:

  • Fasting log — dates you marked as fasted
  • Qada tracking — missed and completed makeup fasts (Women's Mode)
  • Settings — language preference, gender, Hijri adjustment
  • Hijri date cache — temporary cache from the Aladhan API to reduce network requests

You can clear all locally stored data at any time by removing the extension or using Chrome's extension storage clear functionality.

4. Third-Party API

The extension makes requests to the Aladhan API (api.aladhan.com) to convert Gregorian dates to Hijri dates. This request contains only the date being converted — no user-identifying information is sent.

Please review Aladhan's Privacy Policy for information on how they handle API requests.

5. Permissions

The extension requests only the minimum permissions necessary:

  • storage — to save your fasting log and settings locally
  • alarms — to schedule daily fasting reminders
  • notifications — to display reminder notifications
  • https://api.aladhan.com/* — to fetch Hijri date data

No permissions are requested beyond this list.

6. No Advertising or Monetization

The extension contains no advertisements, sponsored content, or any form of monetization. It is provided free of charge as a community utility.

7. Children's Privacy

This extension does not knowingly collect information from children or any users. As no data is collected at all, there are no special concerns regarding minors.

8. Changes to This Policy

If this privacy policy is updated, the revised version will be made available at this same URL. Continued use of the extension after any changes constitutes acceptance of the updated policy.

9. Contact

If you have questions about this privacy policy, you may open an issue on the project's repository or contact the developer through the Chrome Web Store listing page.
